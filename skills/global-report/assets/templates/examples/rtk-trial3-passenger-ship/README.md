# 완성 예시: 3차 RTK 실증 결과 보고 (여객선)

`field-trial-report.html` 틀로 쓸 수 있는 실증 결과 보고서를 실제로 끝까지 만든 예시예요. 새 실증 보고서를 만들 때 장 구성, 표·그림 배치, 출처 표기 방식을 참고해요.

| 파일 | 내용 |
| --- | --- |
| `report.html` | 보고서 원본. 3쪽 PDF로 내보내요. |
| `spec.md` | 목적·독자·문체와 작성 중 내린 결정 기록 |
| `sources.md` | 자료 목록(S1~S10) |
| `sources/photos/` | 보고서에 들어간 그림 4개 |
| `exports/` | 최종 PDF(v13) |

`sources.md`에 적힌 로그, 집계 스크립트, 화면 녹화 장면은 용량과 원본 보관 위치 때문에 넣지 않았어요. `lint_report.mjs`는 그림과 출처 ID만 확인하므로 이 폴더 그대로 검사와 내보내기를 할 수 있어요.

## 참고할 점

- 요약 상자 → 실증 개요 표 → 구간마다 "타임라인 그림 + 비율 표" → 원인 분석 표 → 다음 기준 순서로 썼어요.
- 비율 표는 구간 전체 시간을 100%로 두고 미기록도 칸으로 보여 줘요. 구간 시작은 실제 출항(선속 3kn 이상 첫 기록)으로 정하고 그림 축에 적었어요.
- 매뉴얼 기준을 인용할 때는 장과 쪽 번호를 함께 적고, 줄이 바뀌어도 인용이 끊기지 않게 줄바꿈 없는 공백(nbsp)으로 묶었어요.
